# Discord-бот: Рулетка + монеты

Один файл кода (`index.js`), простое JSON-хранилище, токен не попадает в GitHub.

## Файлы в проекте

- `index.js` — весь код бота
- `package.json` — зависимости (discord.js, dotenv)
- `.env.example` — образец файла с секретами (сам `.env` ты создашь локально)
- `.gitignore` — не даёт `.env` и данным попасть в публичный репозиторий
- `economy.json` — создастся автоматически при первом запуске (в нём хранятся балансы)

## Шаг 1. Создать приложение бота в Discord

1. Открой https://discord.com/developers/applications
2. **New Application** → дай имя → Create
3. Слева вкладка **Bot** → **Reset Token** → скопируй токен (это `DISCORD_TOKEN`). Никому его не показывай и никогда не публикуй.
4. На вкладке **Bot** отдельных Privileged Intents для этого бота включать не нужно — используются только слэш-команды.
5. Вкладка **General Information** → скопируй **Application ID** (это `CLIENT_ID`).

## Шаг 2. Пригласить бота на сервер

1. Вкладка **OAuth2 → URL Generator**
2. Scopes: отметь `bot` и `applications.commands`
3. Bot Permissions: отметь `Send Messages`, `Embed Links`, `Use Slash Commands`
4. Скопируй сгенерированную ссылку внизу, открой её в браузере, выбери свой сервер, Authorize

## Шаг 3. Узнать свой Discord ID и ID сервера

1. В Discord: Настройки → Расширенные → включи **Режим разработчика**
2. ПКМ по своему нику → **Копировать ID пользователя** → это `OWNER_ID` (только ты сможешь выдавать монеты)
3. ПКМ по иконке сервера → **Копировать ID сервера** → это `GUILD_ID` (нужен, чтобы команды появились мгновенно, а не через час)

## Шаг 4. Установить Node.js

Скачай и установи Node.js 18+ с https://nodejs.org (LTS-версия). Проверка: `node -v` в терминале.

## Шаг 5. Настроить проект локально

1. Помести все файлы (`index.js`, `package.json`, `.env.example`, `.gitignore`) в отдельную папку
2. В терминале в этой папке: `npm install`
3. Сделай копию `.env.example` и назови её `.env`
4. Впиши в `.env` реальные значения, полученные на шагах 1–3:
   ```
   DISCORD_TOKEN=реальный_токен
   CLIENT_ID=реальный_application_id
   GUILD_ID=реальный_id_сервера
   OWNER_ID=твой_discord_id
   ```
5. Запусти бота: `npm start` (или `node index.js`)
6. В консоли должно появиться `✅ Бот запущен как ИмяБота#0000`
7. В Discord пропиши `/помощь`, `/профиль`, `/выдать`, `/рулетка` — команды должны появиться сами

Файл `.env` **никогда** не должен попасть в Git — он уже указан в `.gitignore`.

## Шаг 6. Выложить код на GitHub (без токена)

```bash
git init
git add .
git commit -m "Первая версия бота"
```
Создай пустой репозиторий на https://github.com/new, затем:
```bash
git remote add origin https://github.com/твой_логин/твой_репозиторий.git
git branch -M main
git push -u origin main
```
Так как `.env` в `.gitignore`, токен физически не попадёт в репозиторий — на GitHub увидят только `.env.example` с пустыми подписями.

## Шаг 7. Запустить бота 24/7 (GitHub код не «работает» сам по себе)

GitHub — это только хранилище кода, он не держит бота включённым постоянно. Для непрерывной работы выбери один из вариантов:

**Вариант А — Railway.app (проще всего)**
1. Зарегистрируйся на https://railway.app через GitHub
2. New Project → Deploy from GitHub repo → выбери свой репозиторий
3. Во вкладке **Variables** добавь те же 4 переменные, что и в `.env` (`DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`, `OWNER_ID`)
4. Start Command: `npm start`
5. Deploy — бот будет работать постоянно, токен виден только тебе в панели Railway

**Вариант Б — свой компьютер/сервер**
Просто держи терминал с `npm start` запущенным (для теста годится, для «навсегда» — нет, компьютер должен быть постоянно включён).

## Как это работает

- **`/профиль [игрок]`** — баланс, побед/поражений, общий итог по ставкам (+/-)
- **`/выдать <игрок> <количество>`** — только `OWNER_ID` может выдать (или списать, указав отрицательное число) любое количество монет
- **`/рулетка <тип> <значение> <ставка>`** — списывает ставку, крутит `Math.random()` от 0 до 36 (честный рандом, без подкруток и заранее заданных исходов), сверяет с правилами настоящей рулетки, платит по стандартным множителям:
  - число — x36
  - цвет (red/black) — x2
  - чёт/нечет — x2
  - половина (low 1-18 / high 19-36) — x2
  - дюжина (1/2/3) — x3
  - колонка (1/2/3) — x3
  - выпадение зеро (0) — проигрывают все ставки, кроме ставки на число «0» (как в настоящем казино)

Если захочешь изменить множители или добавить свои типы ставок — правь объект `PAYOUTS` и функцию `isWin` в `index.js`.
